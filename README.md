# PassOp - Password Manager 🔐

A secure and responsive password manager application built using React. This app allows you to store, manage, and securely keep track of your passwords locally using the browser's Local Storage.

## 🌐 Live Demo
**[Click here to view the live project](https://Shivam-Kshirsagar.github.io/PassOp-Password-Manager/)**

## ✨ Features
- **Save Passwords:** Securely add website URLs, usernames, and passwords.
- **Local Storage:** All data is saved in your browser's Local Storage, ensuring your data remains on your device.
- **Copy to Clipboard:** Easily copy passwords or usernames with a single click.
- **Edit & Delete:** Manage your saved credentials easily.
- **Responsive Design:** Works smoothly on both desktop and mobile devices.

## 🛠️ Tech Stack
- **Frontend:** React (Vite)
- **Styling:** Tailwind CSS / CSS
- **Storage:** Browser Local Storage
